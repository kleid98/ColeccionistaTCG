# ColeccionistaTCG

Diario de formación y mercado para coleccionar **Pokémon TCG** y **Riftbound** a medio y largo plazo.

- `CLAUDE.md`: la rutina diaria que sigue Claude.
- `conocimiento/principios.md`: reglas de compra y de mantenimiento (van evolucionando).
- `conocimiento/aprendizajes.md`: lo aprendido cada día, con su fuente.
- `watchlist.md`: productos y cartas vigilados, con precio objetivo.
- `informes/`: un informe por día (`AAAA-MM-DD.md`).

Esto no es asesoramiento financiero.
